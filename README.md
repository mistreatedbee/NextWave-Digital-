# NextWave Digital Solutions

Premium digital agency website for **NextWave Digital Solutions** — Johannesburg, South Africa.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion + GSAP
- Lenis smooth scroll
- Supabase (Insforge CMS)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
